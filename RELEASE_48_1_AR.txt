جمعية الخير للجميع — الإصدار 48.1.0 (مرشح موحّد للاختبار)
====================================================

الغرض
-----
هذه الحزمة مبنية على الإصدار 48 الموجود، مع الحفاظ على ملفات التطبيق ووظائفه الحالية. هذا إصدار تجهيز وفحص وتوحيد، وليس إعلانًا عن اكتمال كل وحدات ERP أو نشر قاعدة البيانات.

ما تم في هذه الحزمة
-------------------
1) توحيد رقم الإصدار إلى 48.1.0 في ملف الإصدار وحزمة Windows وإعداد Android.
2) إضافة فاحص إصدار محلي tools/check_release.py.
3) إضافة دليل ترقية ونسخ احتياطي وتراجع: UPGRADE_48_1_AR.txt.
4) إضافة تقرير حالة واختبارات وحدود واضحة: QA_REPORT_48_1_AR.txt.
5) فحص تطابق ملفات الويب الأساسية بين الجذر وWindows ونسختي أصول Android.
6) فحص صياغة ملفات JavaScript المحلية باستخدام node --check.

ما لم يتم
---------
- لم يتم الاتصال بمشروع Supabase الحي أو تعديل قاعدة البيانات.
- لم يتم تشغيل SQL أو تفعيل RLS أو تغيير صلاحيات الموظفين.
- لم يتم إنشاء APK أو EXE ولم يتم توقيع أي تطبيق.
- لم يتم إجراء اختبار وظيفي شامل على حسابات وأدوار حقيقية.
- لم يتم استكمال وحدات ERP الجديدة غير الموجودة بالفعل؛ لا تعتبر الواجهات أو التقارير الحالية بديلًا عن مراجعة محاسب أو باحث اجتماعي.

تنبيه بيانات الأطفال
--------------------
وجود children_registry_security_v48.sql داخل الملفات لا يعني أنه مطبق على Supabase. لا تدخل بيانات أطفال حقيقية قبل مراجعة وتنفيذ خطة الترقية واختبار منع القراءة والكتابة لكل دور على بيئة اختبار.
